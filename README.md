Responsive Portfolio

Project Overview

Responsive Portfolio is a frontend web project showcasing the portfolios of three individuals. 
The website is designed with responsiveness in mind, ensuring a smooth experience across different devices and screen sizes. 
It features a secure login interface that directs users to their respective portfolios based on the credentials provided.

Features

✅ Responsive design using HTML, CSS, and JavaScript

✅ Individual portfolio pages for each user

✅ Login system with user authentication (demo purpose only)

✅ Clean file structure for easy scalability

✅ Centralized styling and scripting for all pages

 Project Structure:
 ├── index.html        # Portfolio for Sumit   
├── index1.html       # Portfolio for Vedant 
├── index2.html       # Portfolio for Sukhpreet  
├── styles.css        # Common stylesheet  
├── script.js         # Common JavaScript functionality  
├── demo.html         # Login page  
├── demo.css          # Styles for the login page  
├── modal.js          # JavaScript for login modal functionality  
└── users.json        # Stores user credentials 


Login Page
Users are greeted with a login interface (demo.html). After entering their username and password (data fetched from users.json), they are redirected to their corresponding portfolio page. The login logic is handled by modal.js.
